# Use Cases - Smart Attachments

## UC-01. Автоматическое создание заметки-каталога

**Актёр:** пользователь Obsidian
**Предусловие:** плагин включён, папки `attachments` и `catalog` настроены
**Триггер:** в папке `attachments` появляется новый файл

**Основной поток:**
1. Пользователь копирует файл в папку `attachments`.
2. Плагин фиксирует событие создания файла.
3. Плагин вычисляет SHA-256 хеш файла.
4. Проверяет, нет ли уже записи с таким хешем (защита от дублей).
5. Создаёт Markdown-заметку в папке `catalog` по шаблону.
6. Записывает метаданные в YAML-фронтматтер: путь, имя, расширение, размер, хеш, дату.
7. Добавляет запись в индекс.

**Постусловие:** в `catalog` появилась заметка, файл в индексе.

**Альтернативный поток (дубликат):**
- Если файл с таким же хешем уже есть - новая заметка не создаётся, запись не добавляется.

## UC-02. Обновление при переименовании файла

**Актёр:** пользователь
**Предусловие:** файл существует в `attachments` и есть в индексе
**Триггер:** файл переименован

**Основной поток:**
1. Пользователь переименовывает файл в `attachments`.
2. Плагин фиксирует событие переименования.
3. Находит запись в индексе по старому пути.
4. Обновляет путь и имя в индексе.
5. Обновляет в заметке путь, имя и заголовок.
6. Сохраняет индекс.

**Постусловие:** в заметке актуальный путь и имя файла; имя самой заметки не меняется.

**Исключение:**
- Если запись в индексе не найдена - операция пропускается, в консоль пишется предупреждение.

## UC-03. Пометка orphan при удалении файла

**Актёр:** пользователь
**Предусловие:** файл существует в `attachments` и есть в индексе
**Триггер:** файл удалён

**Основной поток:**
1. Пользователь удаляет файл из `attachments`.
2. Плагин фиксирует событие удаления.
3. Находит запись в индексе.
4. Меняет статус на `orphan`, записывает дату удаления.
5. В заметке меняет `status: active` на `status: orphan`.
6. Сохраняет индекс.

**Постусловие:** заметка остаётся в `catalog`, но помечена как orphan.

## UC-04. Пересборка индекса

**Актёр:** пользователь
**Триггер:** команда «Rebuild attachments index» из палитры команд

**Основной поток:**
1. Пользователь открывает палитру команд (Ctrl+P).
2. Вводит «Rebuild attachments index» → Enter.
3. Плагин сканирует папку `attachments`.
4. Для каждого файла, которого нет в индексе, создаёт заметку и запись.
5. Для каждой active-записи, файла которой нет, ставит статус `orphan`.
6. Выводит уведомление: «Rebuild done: created N, orphans M».

**Постусловие:** индекс синхронизирован с файловой системой.

## UC-05. Удаление всех orphan-заметок

**Актёр:** пользователь
**Триггер:** команда «Delete all orphan notes»

**Основной поток:**
1. Пользователь открывает палитру команд.
2. Вводит «Delete all orphan notes» → Enter.
3. Плагин проходит по индексу, находит записи со статусом `orphan`.
4. Удаляет соответствующие заметки из `catalog`.
5. Удаляет записи из индекса.
6. Выводит уведомление: «Deleted N orphan notes».

**Постусловие:** orphan-заметки удалены, active-заметки не тронуты.
