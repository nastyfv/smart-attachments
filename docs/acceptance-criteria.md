# Критерии приёмки - Smart Attachments

Формат: Given-When-Then.

## AC-01. Создание заметки при появлении файла

**Given** плагин включён, папки `attachments` и `catalog` настроены  
**When** в папку `attachments` добавлен файл `test.pdf`  
**Then** в папке `catalog` появляется заметка `test.md` в течение 1 секунды  
**And** в фронтматтере заметки заполнены поля `file`, `name`, `ext`, `size`, `hash`, `created`  
**And** `status: active`

## AC-02. Защита от дублей

**Given** в `attachments` уже есть файл с хешем H  
**When** в `attachments` добавлен другой файл с тем же хешем H  
**Then** новая заметка не создаётся  
**And** в индексе остаётся одна запись

## AC-03. Переименование файла

**Given** файл `picture.jpg` есть в `attachments` и в индексе  
**When** файл переименован в `picture 1.jpg`  
**Then** в заметке `catalog/picture.md` поле `file` содержит `attachments/picture 1.jpg`  
**And** заголовок заметки содержит `# picture 1.jpg`  
**And** имя самой заметки остаётся `picture.md`

## AC-04. Удаление файла

**Given** файл `picture.jpg` есть в `attachments` и в индексе  
**When** файл удалён  
**Then** в заметке `catalog/picture.md` поле `status` меняется на `orphan`  
**And** добавляется поле `deletedAt` с датой  
**And** сама заметка не удаляется

## AC-05. Пересборка индекса

**Given** в `attachments` есть файлы, которых нет в индексе, и в индексе есть записи без файлов  
**When** запущена команда «Rebuild attachments index»  
**Then** для файлов без записи создаются заметки и записи  
**And** записи без файлов помечаются `orphan`  
**And** выводится уведомление с количеством созданных и помеченных

## AC-06. Удаление orphan-заметок

**Given** в индексе есть записи со статусом `orphan`  
**When** запущена команда «Delete all orphan notes»  
**Then** соответствующие заметки удаляются из `catalog`  
**And** записи удаляются из индекса  
**And** active-заметки не затрагиваются  
**And** выводится уведомление с количеством удалённых

## Нефункциональные 

- NFR-01: время реакции на создание файла ≤ 1 сек для файлов до 10 МБ.
- NFR-02: пересборка индекса до 10 000 файлов без зависания UI.
- NFR-03: плагин не выполняет сетевых запросов.
- NFR-04: плагин работает только на desktop (Windows/macOS/Linux).
