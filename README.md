# Smart Attachments

Плагин для Obsidian: автоматически создаёт заметку-каталог для каждого вложения в vault, с метаданными и поддержкой актуальности при изменении файлов.

## Проблема

В Obsidian вложения (PDF, изображения, документы, архивы) — «чёрный ящик»: нет единого каталога, нет метаданных, нет связей с заметками. При переименовании и удалении файлов связи теряются.

## Что делает плагин

- **Создание.** При появлении файла в папке `attachments` автоматически создаёт заметку в `catalog` с метаданными: путь, имя, размер, тип, SHA-256 хеш, дата.
- **Переименование.** При переименовании файла обновляет путь, имя и заголовок в заметке. Имя самой заметки остаётся прежним — чтобы не ломать обратные ссылки.
- **Удаление.** При удалении файла помечает заметку как `orphan` с датой удаления. Заметка не удаляется — сохраняется история.
- **Rebuild index.** Команда для пересборки индекса: создаёт недостающие заметки, помечает пропавшие файлы как `orphan`, выводит отчёт.
- **Delete all orphan notes.** Команда для очистки каталога от заметок с удалёнными файлами.
